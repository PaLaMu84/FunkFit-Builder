# FunkFit Builder v0.7.2

## Implementerede rettelser

- Builder er standard; AI-forslag er et valgfrit spor.
- Finisher er altid én sang med titel, kunstner, link og længde.
- Billedimport kan vælges separat fra galleri eller kamera.
- OCR bruger billedforbedring, dansk + engelsk genkendelse og mere tolerant øvelsesmatch.
- Fast ledopvarmning på cirka fem minutter kan planlægges før pulsopvarmningen.
- Fleksibel struktur med et, to eller tre hovedelementer.
- TRX er en selvstændig træningstype.
- Felter i finpudsning skifter efter Junior, Familie, Funktionel voksen, HIIT, Hyrox og TRX.
- Feltkonfigurationen er forberedt til personlige brugerprofiler.
- AI nedprioriterer nyligt brugte øvelser og bruger programmeringsregler pr. træningsspor.
- “Sjov” giver konkrete lege, makker- eller konkurrenceelementer.
- Menupunkt og knapper bruger konsekvent navnet “Mit bibliotek”.
- Tid, format, arbejde/pause og runder kan ændres direkte i sektionsoverskriften.
- Samlet tidskontrol skelner mellem fast program og valgfri finisher.
