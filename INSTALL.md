# Installation fra ZIP

1. Pak ZIP-filen ud.
2. Kopiér alle filer og mapper over i dit lokale FunkFit Builder-repository.
3. Commit på develop:
   `v0.7.4-alpha format model, running and section AI`
4. Push til GitHub.
5. Åbn `reset-cache.html` én gang.
6. Genåbn appen og test efter TESTLISTE.md.

Dette er en alpha-testversion. Gemte data bruger nye lokale nøgler, så den kan testes uden at overskrive v0.7.3-data.
